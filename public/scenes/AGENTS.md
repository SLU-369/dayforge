# 3D scene assets

## Purpose

- Own retained, redistributable assets for the inactive B.3.1 experiment. The current photographic environment must not download this castle or its decoders.

## Ownership

- `castle/castle.glb`: adapted Ju Designer geometry with replacement CC0 materials.
- `castle/ATTRIBUTION.md`: source, license boundaries, modifications and checksums.
- `basis/`: unmodified Three.js 0.186.0 Basis transcoder and Apache 2.0 license, used locally by KTX2Loader.

## Local Contracts

- Never include the original ZIP, Blender sources, or Textures.com images in public assets or Git.
- Preserve the model's CC BY 4.0 attribution; the repository code license does not replace asset licenses.
- Retain the original source outside public assets and Git. The preview is not the final cinematic scene.

## Work Guidance

- Inspect embedded images and extension requirements after every conversion.
- Keep the B.3.1 static model separate from future animated window/character assets.

## Verification

- Run asset structure tests; active browser tests verify no castle-model downloads. Loading/fallback evidence for the old proof is historical, not current visual acceptance.
